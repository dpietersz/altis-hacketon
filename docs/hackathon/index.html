Lovable Git repo — how to find it

  1. Open the Lovable project in the browser.
  2. Check Share / GitHub / Source code / Export in Lovable’s project settings. Lovable usually shows the connected GitHub repo URL there if GitHub sync was enabled.
  3. If no repo is connected, use Lovable’s Connect GitHub or Export to GitHub action, then choose/create the repository.
  4. Copy the GitHub HTTPS or SSH URL and run git clone <repo-url>.
  5. If the app is deployed but repo is unclear, inspect the Lovable project owner/workspace, GitHub account used for OAuth, and recent repositories created around the hackathon date.

When you provide the repo URL, clone path, or downloaded source, this doc set can be extended with frontend architecture and dashboard component mapping.
